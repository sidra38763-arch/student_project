# Sunday Project: Data Quality, Insights & CSV Operations

AI Engineering Bootcamp | Module 02

## How to run
1. Keep all files in the same folder: Sunday_Project.ipynb and sales_raw.csv.
2. Open Sunday_Project.ipynb in Jupyter Notebook or Google Colab (in Colab, upload sales_raw.csv first).
3. Click Run All. Part A creates cleaned_sales.csv, Part B reads it and creates sales_updated.csv.

## Files
- Sunday_Project.ipynb: notebook (Part A and Part B)
- sales_raw.csv: original input (never modified)
- cleaned_sales.csv: output of Part A
- sales_updated.csv: output of Part B
